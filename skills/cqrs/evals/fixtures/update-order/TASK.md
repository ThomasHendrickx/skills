Customers should be able to change the shipping address of their order (street, city, postcode) from the order page until it ships; a shipped order's address can no longer change. Today the only way to change an order is `UpdateOrder` (`update_order` in `src/core/commands/update_order.py`), which the staff edit screen (`put_order` in `src/web/order_pages.py`) uses to save the whole order.
